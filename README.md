# JAN読み取り

物品のバーコード（JANコード）を、スマホで読み取るためだけのページです。

## できること

- スマホのカメラをバーコードにかざすと、JANコードを読み取る
- 読んだコードは一覧に貯まる（画面を閉じても残る）
- 一覧をまとめてコピーできる

## 大事なこと

- 読み取りは**その端末の中だけ**で行っています。画像もコードも、どこにも送信していません
- そのため、院内のデータは一切含まれていません
- サーバーを使わないので、置き場所は静的なホスティング（GitHub Pages など）だけで足ります

## 中身

| ファイル | 中身 |
|---|---|
| `index.html` | 画面と読み取りの処理（これ1枚で動きます） |
| `vendor/zxing.min.js` | 読み取り部品。iPhoneのように読み取り機能を内蔵していない端末で使われます |

Androidの Chrome は読み取り機能を内蔵しているので、そちらが優先して使われます。

## 注意

スマホのカメラは、**鍵マークの付いたアドレス（https）でないと開きません**。
院内アドレス（`http://...`）に置いても、カメラのボタンを押して何も起きない状態になります。
GitHub Pages はhttpsが付くので、そのまま使えます。

パソコンで試すときは `http://localhost` なら鍵マーク無しでもカメラが開きます。
